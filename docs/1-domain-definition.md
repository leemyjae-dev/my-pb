# my-pb 도메인 정의서 (초안)

## 1. 서비스 개요 및 목적

- **서비스명**: my-pb (AI 기반 프라이빗뱅킹 서비스)
- **문제 의식**: 전통적인 PB(Private Banking) 서비스는 고액 자산가에게만 제공되어 왔다. my-pb는 AI를 통해 이 자산관리 서비스의 접근성을 일반 사용자에게까지 넓히는 것을 목표로 한다.
- **핵심 가치 제안**: 사용자의 나이, 급여, 자산 등 개인 정보를 바탕으로 적절한 자산 배분(asset allocation) 원칙을 가이드하고, 사용자가 이를 자신의 상황에 맞게 조정할 수 있도록 돕는다.
- **초안 범위**: 이 문서는 회원가입/로그인, 사용자 정보 입력, 자산 포트폴리오 생성 및 조정이라는 4가지 핵심 기능을 도메인 관점에서 정의한다. 기술 스택이나 DB 스키마는 다루지 않는다.

---

## 2. 핵심 도메인 용어 정의 (Ubiquitous Language)

| 용어 | 정의 |
|---|---|
| **사용자(User)** | my-pb 서비스에 가입하여 인증을 통해 서비스를 이용하는 주체 |
| **사용자 프로필(User Profile)** | 자산 배분 가이드를 산출하기 위해 필요한 사용자의 개인 정보(나이, 급여, 자산 등)의 집합 |
| **리스크 성향(Risk Profile)** | 사용자가 감내할 수 있는 투자 위험의 수준. 자산 배분 가이드 산출에 영향을 주는 요소 |
| **자산 항목(Asset Item)** | 사용자가 보유한 개별 자산(예: 예금, 주식, 부동산 등)을 나타내는 단위 |
| **자산군(Asset Class)** | 자산 항목을 분류하는 카테고리(예: 현금성 자산, 주식, 채권, 부동산 등) |
| **자산 포트폴리오(Asset Portfolio)** | 사용자가 보유한 자산 항목들과, 자산군별 배분 비중을 종합적으로 나타내는 사용자 자산 현황의 집합체 |
| **자산 배분(Asset Allocation)** | 자산 포트폴리오 내에서 자산군별로 어느 정도 비중을 두는지를 나타내는 구성. 비중의 합은 100%가 되어야 함 |
| **자산 배분 원칙(Asset Allocation Guideline)** | 사용자 프로필(나이, 급여, 자산, 리스크 성향 등)을 바탕으로 AI가 산출하여 제시하는 권장 자산 배분안 |
| **조정(Adjustment)** | 사용자가 AI가 제시한 자산 배분 원칙을 자신의 판단에 따라 직접 수정하는 행위 |

> **확인 필요**: "리스크 성향"이 사용자가 직접 입력하는 값인지, 사용자 프로필(나이/급여/자산 등)로부터 AI가 자동으로 산출하는 값인지 요구사항에 명시되어 있지 않음. 이번 초안에서는 도메인 용어로만 정의하고, 산출 방식은 범위 밖으로 둔다.

## 3. 핵심 엔티티와 속성 (도메인 모델 수준)

DB 스키마가 아닌 개념 수준의 속성만 나열한다.

### 3.1 사용자(User)
- 식별자
- 인증 정보(이메일/비밀번호 등 — 방식은 확인 필요)
- 가입일시
- 사용자 프로필(1:1 연관)
- 자산 포트폴리오(1:1 또는 1:N 연관 — 확인 필요)

### 3.2 사용자 프로필(User Profile)
- 나이
- 급여(소득)
- 보유 자산 총액(또는 자산 항목 목록으로부터 산출)
- 리스크 성향 (선택적/확인 필요)
- 기타 자산 배분 산출에 필요한 정보 (확인 필요 — 예: 투자 목적, 투자 기간 등)

### 3.3 자산 포트폴리오(Asset Portfolio)
- 식별자
- 소유 사용자
- 자산 항목 목록
- 자산 배분(자산군별 비중)
- 최종 수정일시

### 3.4 자산 항목(Asset Item)
- 식별자
- 소속 자산군
- 명칭/설명
- 평가 금액

### 3.5 자산군(Asset Class)
- 식별자
- 명칭(예: 현금성 자산, 주식, 채권, 부동산 등)

> **확인 필요**: 자산군의 종류/분류 체계가 사전에 정의되어야 하는지, 몇 개의 자산군을 지원할지 명시되지 않음. 이번 초안에서는 개념만 정의하고 구체적인 목록은 정하지 않는다.

### 3.6 자산 배분 원칙(Asset Allocation Guideline)
- 식별자
- 산출 기준이 된 사용자 프로필 스냅샷(또는 참조)
- 자산군별 권장 비중
- 산출일시

## 4. 엔티티 간 관계 (개략도)

```
User (사용자)
 ├─ 1:1 ─ UserProfile (사용자 프로필: 나이, 급여, 자산, 리스크 성향 등)
 └─ 1:1 ─ AssetPortfolio (자산 포트폴리오)
              ├─ 1:N ─ AssetItem (자산 항목) ─ N:1 ─ AssetClass (자산군)
              ├─ 1:1 ─ AssetAllocation (자산 배분: 자산군별 비중)
              └─ (참조) AssetAllocationGuideline (AI가 제시한 권장 배분안)
```

- 사용자는 하나의 사용자 프로필과 하나의 자산 포트폴리오를 갖는다. (1인당 여러 포트폴리오를 가질 수 있는지는 확인 필요)
- 자산 포트폴리오는 여러 개의 자산 항목으로 구성된다.
- 각 자산 항목은 하나의 자산군에 속한다.
- 자산 배분은 자산 포트폴리오 내 자산군별 비중을 나타낸다.
- 자산 배분 원칙(AI 권장안)은 사용자 프로필을 입력으로 산출되며, 사용자는 이를 참고하여 자산 배분을 조정할 수 있다.

## 5. 핵심 유스케이스/시나리오

### UC-1. 회원가입 및 로그인(인증)
- 사용자는 회원가입을 통해 계정을 생성한다.
- 사용자는 로그인을 통해 인증된 상태에서만 앱의 기능을 사용할 수 있다.

### UC-2. 사용자 정보 수정
- 로그인한 사용자는 자신의 계정 정보(인증 정보 등) 및 프로필 정보를 조회하고 수정할 수 있다.

### UC-3. 사용자 프로필(자산관리 관련 정보) 입력
- 사용자는 자산 포트폴리오 생성을 위해 필요한 정보(나이, 급여, 자산 등)를 입력한다.
- 입력된 정보를 바탕으로 AI가 자산 배분 원칙(권장 배분안)을 산출한다.

### UC-4. 자산 포트폴리오 생성
- 사용자 프로필 입력 정보와 AI가 산출한 자산 배분 원칙을 바탕으로 초기 자산 포트폴리오가 생성된다.

### UC-5. 자산 포트폴리오 조정
- 사용자는 AI가 제시한 자산 배분을 확인하고, 자산군별 비중을 자신이 원하는 대로 조정할 수 있다.
- 조정된 자산 배분은 저장되어 사용자의 현재 자산 포트폴리오에 반영된다.

## 6. 도메인 규칙/제약사항

- 사용자는 인증(로그인)된 상태에서만 자신의 정보 및 자산 포트폴리오에 접근/수정할 수 있다.
- 자산 포트폴리오 내 자산 배분(자산군별 비중)의 합은 항상 100%가 되어야 한다.
- 자산 배분 조정은 사용자 본인의 포트폴리오에 대해서만 가능하다.

> **확인 필요**: 위 규칙 외에 다음과 같은 추가 제약이 필요한지 요구사항에 명시되어 있지 않아 이번 초안에서는 다루지 않음.
> - 특정 자산군에 대한 최소/최대 비중 제한 여부
> - 나이/리스크 성향에 따른 배분 조정 가능 범위 제한 여부
> - 자산 항목별 최소 입력 금액, 음수 불가 등의 유효성 규칙

## 7. 범위 밖 (Out of Scope)

이번 초안에서는 다음 항목을 다루지 않는다. (요구사항에 명시되지 않았으며, 임의로 범위를 확장하지 않기 위함)

- 실제 금융상품 매매/거래 연동
- 세금 계산 및 절세 전략
- 실시간 시세 연동, 자산 가치 자동 평가
- 외부 금융기관 계좌 연동(마이데이터 등)
- 다중 포트폴리오 관리, 포트폴리오 이력/버전 관리
- 알림, 리밸런싱 자동 실행 등의 부가 기능
- 결제/구독 등 과금 모델
- 관리자(어드민) 기능

## 8. 확인이 필요한 가정/질문 목록

문서 전체에서 등장한 "확인 필요" 항목을 모아 정리한다. 아래 사항은 요구사항에 명시되지 않아 임의로 결정하지 않았다.

1. **인증 방식**: 이메일/비밀번호 기반인지, 소셜 로그인 등을 포함하는지?
2. **리스크 성향 산출 방식**: 사용자가 직접 입력(설문 등)하는지, 사용자 프로필로부터 AI가 자동 산출하는지?
3. **사용자 프로필 항목의 범위**: 나이/급여/자산 외에 투자 목적, 투자 기간, 부양가족 등 추가로 필요한 정보가 있는지?
4. **자산군 분류 체계**: 지원할 자산군의 구체적인 종류와 개수(예: 현금성 자산/주식/채권/부동산/기타 등)가 사전에 정의되어야 하는지?
5. **포트폴리오 다중 보유 여부**: 사용자 1인이 여러 개의 자산 포트폴리오를 가질 수 있는지, 1:1로 고정인지?
6. **자산 배분 조정의 범위 제한**: 사용자가 AI 권장안과 무관하게 자유롭게 조정 가능한지, 아니면 일정 범위 내에서만 허용되는지?
7. **자산 배분 원칙(AI 권장안)의 재산출 시점**: 프로필 수정 시마다 자동으로 재산출되는지, 사용자가 요청할 때만 산출되는지?
8. **자산 항목의 평가금액 관리 방식**: 사용자가 수동으로 입력/갱신하는지, 외부 연동을 통한 자동 갱신을 전제하는지(→ 현재는 Out of Scope로 가정)?

## 1. 서비스 개요 및 목적

개인 투자자가 다음 세 가지를 한 번에 확인하고, 본인의 실제 투자가 적절한지 스스로 진단할 수 있도록 돕는 개인용 애플리케이션이다.

1. 공식 투자자성향 (증권사 표준 KYC 설문 기반 5단계 분류)
2. 심리적 성향 (IPIP 신경성 10문항 기반 손실민감도)
3. 실제 보유 자산배분 (증권 계좌 스크린샷 기반)

기존 증권사 투자자성향분석은 자기보고식 설문에 그쳐 실제 심리적 손실감내도나 투자행동을 반영하지 못한다는 문제의식에서 출발하며, 위 세 가지를 대조하여 "성향·심리 대비 실제 투자가 적절한가"를 판정하고 구체적인 조정 방향을 안내하는 것이 서비스의 핵심 목적이다.

## 2. 핵심 도메인 용어 정의 (Ubiquitous Language)

| 용어 | 정의 |
|---|---|
| 투자자성향(KYC) | 표준 KYC 설문(위험감내도·투자경험·투자목적 등 10개 문항)의 응답 점수를 합산해 분류한 5단계 등급(안정형/안정추구형/위험중립형/적극투자형/공격투자형) |
| 신경성 점수 | IPIP-50 중 신경성 하위척도 10문항 응답을 채점해 산출한 점수. 손실에 대한 심리적 민감도를 추정하는 지표로 사용 |
| 심리민감도(손실민감도) | 신경성 점수를 기준값과 비교해 판정한 '높음/보통' 등급. 신경성 점수가 평균 대비 1표준편차 이상(상위 약 16%)이면 '높음'으로 판정 |
| 역채점 문항 | IPIP 문항 중 진술 방향이 반대인 문항으로, 점수를 반전(6-응답값)하여 합산하는 문항 |
| 실보유 자산배분 | 사용자가 업로드한 증권 계좌 스크린샷에서 인식된 종목·수량·평가금액을 자산군별로 집계한 실제 비중 |
| 자산군 | 실보유 종목을 분류하는 상위 카테고리(예: 주식/채권/펀드/현금성자산 등) |
| 성향기준 비중 | 특정 투자자성향 등급에 대응하는 권장 자산군별 비중(예: 안정추구형의 주식 비중 기준 30%) |
| 정합성/괴리 | 성향기준 비중과 실보유 자산배분을 비교해 일치하는지(정합) 혹은 초과/과소 등 차이가 나는지(괴리) 판정한 결과 |
| 리스크 진단 결과 | 투자자성향, 심리민감도, 실보유 자산배분 세 가지를 결합해 산출한 최종 진단(적절/부적절 여부, 괴리 원인, 조정 방향, 심리적 부담 안내 등) |

## 3. 핵심 엔티티와 속성 (도메인 모델 수준)

DB 스키마가 아닌 개념 모델이며, 구체적인 필드 타입·저장 방식은 정하지 않는다.

- **사용자(User)**
  - 식별자, 진단 이력에 대한 소유권

- **투자자성향 진단결과(KycProfileResult)**
  - 사용자 참조
  - 문항별 응답 목록 (10개 문항, 각 1~5점)
  - 총점(100점 환산)
  - 성향 등급(안정형/안정추구형/위험중립형/적극투자형/공격투자형)
  - 응시 일시

- **IPIP 신경성 검사결과(NeuroticismTestResult)**
  - 사용자 참조
  - 문항별 응답 목록 (10개 문항, 각 1~5점, 정채점/역채점 구분)
  - 신경성 총점
  - 심리민감도 등급(높음/보통)
  - 응시 일시

- **보유잔고 스냅샷(HoldingsSnapshot)**
  - 사용자 참조
  - 원본 스크린샷 이미지 참조
  - 자산 항목 목록
  - 자산군별 집계 비중
  - 업로드/보정 완료 일시

- **자산 항목(HoldingItem)**
  - 보유잔고 스냅샷 참조
  - 종목명(인식된 원본 텍스트)
  - 수량
  - 평가금액
  - 자산군 분류(자동 분류 결과 또는 사용자 보정값)
  - 분류 확정 여부(자동 분류 확정/사용자 보정 필요/사용자 보정 완료)

- **자산군(AssetClass)**
  - 자산군 명칭(주식/채권/펀드/현금성자산 등)
  - 성향 등급별 기준 비중과의 매핑 근거

- **리스크 진단 결과(RiskDiagnosisResult)**
  - 사용자 참조
  - 참조한 투자자성향 진단결과
  - 참조한 IPIP 신경성 검사결과
  - 참조한 보유잔고 스냅샷
  - 정합성/괴리 판정 (자산군별)
  - 심리적 부담 안내 포함 여부(심리민감도 '높음'이고 괴리가 있는 경우)
  - 조정 방향 피드백 메시지
  - 진단 일시

## 4. 엔티티 간 관계

- 사용자 1 : N 투자자성향 진단결과 (재응시 가능)
- 사용자 1 : N IPIP 신경성 검사결과 (재응시 가능)
- 사용자 1 : N 보유잔고 스냅샷 (재업로드 가능)
- 보유잔고 스냅샷 1 : N 자산 항목
- 자산 항목 N : 1 자산군
- 리스크 진단 결과는 특정 시점의 투자자성향 진단결과 1건, IPIP 신경성 검사결과 1건, 보유잔고 스냅샷 1건을 각각 정확히 1개씩 참조하여 생성됨 (3자 대조 결과물)
- 사용자 1 : N 리스크 진단 결과 (진단 시점마다 새로운 결과 생성)

## 5. 핵심 유스케이스 (4단계 진단 플로우)

1. **투자자성향 설문 응시**: 사용자가 10개 문항에 응답 → 총점 계산 → 5단계 등급 산출 → 투자자성향 진단결과 생성
2. **IPIP 신경성 검사 응시**: 사용자가 10개 문항에 응답 → 역채점 문항 반전 처리 → 총점 계산 → 심리민감도 등급(높음/보통) 산출 → IPIP 신경성 검사결과 생성
3. **잔고 스크린샷 업로드 및 보정**: 사용자가 증권 계좌 스크린샷 업로드 → 종목명·수량·평가금액 인식 → 종목별 자산군 자동 분류 → 분류가 애매한 항목은 사용자가 직접 확인·수정 → 자산군별 비중 확정 → 보유잔고 스냅샷 생성
4. **종합 진단 결과 확인**: 위 세 가지 결과를 결합 → 성향기준 비중 대비 실보유 자산배분의 정합성/괴리 판정 → 심리민감도가 높은 경우 심리적 부담 안내 추가 → 조정 방향(또는 정합 시 긍정 피드백) 메시지 생성 → 리스크 진단 결과로 사용자에게 제공

## 6. 도메인 규칙/제약사항

- **투자자성향 채점**: 문항 10개, 각 1~5점 응답, 합산 후 100점 만점으로 환산. 0~19점 안정형, 20~39점 안정추구형, 40~59점 위험중립형, 60~79점 적극투자형, 80~100점 공격투자형으로 분류
- **IPIP 신경성 채점**: 문항 10개, 각 1~5점(전혀 그렇지 않다~매우 그렇다) 응답. 역채점 문항은 `6 - 응답값`으로 반전 후 합산
- **심리민감도(신경성 '높음') 판정 기준**: 신경성 총점이 평균 대비 1표준편차 이상(상위 약 16%)일 경우 '높음'으로 분류 (표준화 검사 관행 준용)
- **정합성/괴리 판정 로직**: 투자자성향 등급별 성향기준 비중과 실보유 자산배분(자산군별 비중)을 비교하여 초과/과소 여부 판정. 예: 안정추구형 기준 주식 30% 대비 실보유 68%인 경우 '괴리(초과)'로 판정. 몇 %p 이상 차이부터 '괴리'로 판정할지의 허용 오차(임계값)는 미정 — 8절 참조
- **심리적 부담 가중 안내**: 괴리가 있고 동시에 심리민감도가 '높음'인 경우, 해당 초과 투자가 심리적으로 더 큰 부담이 될 수 있음을 피드백에 함께 안내
- **정합 시 피드백**: 성향·심리·실보유잔고가 모두 정합적인 경우 긍정적 피드백 제공
- **자산 항목 보정 규칙**: 자동 분류가 애매한 종목은 반드시 사용자 보정 단계를 거친 뒤에만 자산군별 비중 계산에 확정 반영

## 7. 범위 밖 (Out of Scope)

- 증권사 API를 통한 실시간 계좌 연동 (기관 제휴가 필요해 개인 프로젝트 범위를 벗어남 → 스크린샷 업로드 방식으로 대체)
- 실제 매매(주문 체결) 기능
- 실시간 시세 조회/연동
- 신경성 외 다른 Big Five 성격 요인(외향성·성실성·개방성·우호성) 측정 및 진단 반영 — 기획서는 손실민감도 판별에 신경성만 근거로 채택
- IPIP 50문항 전체 시행 (신경성 10문항만 발췌 시행)

## 8. 확인이 필요한 가정/질문 목록

- **투자자성향 설문 문항·배점**: 기획서 별첨1은 "예시" 문항이며 "실제 구현 시 문항 수·배점은 조정될 수 있음"이라고 명시됨 → 최종 문항 구성·배점·구간 확정 필요
- **IPIP 신경성 문항의 한국어 번역본**: 기획서 별첨2는 영문 IPIP 원문항을 발췌 번역한 예시이며, "정식 서비스화 시에는 국내 타당화 연구에서 검증된 한국어 역문항 사용을 권장"한다고 명시됨 → 실제 사용할 한국어 검증 번역본 출처 확정 필요
- **신경성 '높음' 판정 기준값(평균·표준편차)의 출처**: "표준화 검사 관행상 평균 대비 1표준편차 이상"이라는 기준이 어떤 규준집단(norm)의 평균/표준편차를 사용할지 미정 (자체 수집 데이터 기반인지, 선행연구의 규준을 사용할지)
- **성향기준 비중표**: 기획서 예시(안정추구형 주식 기준 30%)는 1건만 제시되어 있어, 5단계 성향 등급별 전체 자산군 기준 비중표를 별도로 정의해야 함
- **OCR/AI 비전 방식 구체화**: "이미지 인식(OCR/AI 비전)을 통해 종목명·수량·평가금액 등을 추출"이라고만 명시되어 있어, 구체적인 인식 방식·정확도 목표·실패(인식 불가) 시 처리 흐름은 미정
- **종목명 → 자산군 자동 분류 로직의 기준 데이터**: 어떤 참조 데이터(종목 마스터 등)로 자산군을 자동 분류할지 미정
- **애매한 종목 보정 UI 흐름**: "분류가 애매한 종목은 사용자가 직접 확인·수정할 수 있는 보정 단계를 둠"이라고만 명시되어 있어, 애매함을 판단하는 기준과 구체적인 보정 UX는 미정
- **진단 이력 관리 방식**: PRD v1.1에서 2일 MVP 범위상 재응시/재업로드 시 새 결과를 별도 생성하되 종합 진단에는 각 입력의 가장 최근 결과만 사용하고, 과거 이력 추이 조회 기능은 범위 밖으로 확정함(PRD 3절, FR-1.4/FR-2.5/FR-3.6/FR-4.1). MVP 이후 이력 추이 기능을 제공할지는 여전히 확인 필요
- **정합성/괴리 판정 임계값(허용 오차)**: 성향기준 비중과 실보유 자산배분의 차이가 몇 %p 이상일 때 '괴리'로 판정할지 기준값이 기획서에 명시되어 있지 않음 → 서비스 핵심 판정 로직이므로 확정 필요
- **계좌 스크린샷 원본 이미지의 보관/파기 정책**: 민감한 금융 정보가 담긴 원본 이미지를 얼마나 보관할지, 파기 시점·방식은 어떻게 할지 기획서에 명시되어 있지 않음 → 개인정보 처리 관점에서 확정 필요
